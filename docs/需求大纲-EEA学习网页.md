## 一、书本体理解（已完成调研）

**书籍信息**
- 书名：*English for Everyday Activities: A Picture Process Dictionary*（日常生活英语：图解流程词典）
- 作者：Lawrence J. Zwier；出版：New Readers Press（北美版，c1999）
- 用户提供的 PDF：扫描版，78 页 = 封面 + 目录 + 正文书页 6–80。
  - 缺失部分：书页 4–5（To the Student 致读者）、书页 81–96（Index 索引 / Notes on Irregular Forms 不规则动词表 / Processes: My Way 练习 / Notes to the Teacher 教学说明）。
- 内容结构：**6 大 Section × 61 个单元**，覆盖一天生活全流程：

| Section | 主题 | 单元范围 | 数量 |
|---|---|---|---|
| 1 | Starting the Day 开启一天 | 1–11（起床、洗漱、穿衣、早餐、出门） | 11 |
| 2 | Getting Around 出行 | 12–19（公交、开车、火车、出租、步行、骑车） | 8 |
| 3 | At Home in the Evening 晚间居家 | 20–34（回家、做饭、用餐、洗碗、休闲、就寝） | 15 |
| 4 | Managing a Household 家务管理 | 35–50（洗衣、打扫、养宠、园艺、修车、购物、银行） | 16 |
| 5 | Keeping in Touch 保持联络 | 51–57（电话、留言、写信、寄信） | 7 |
| 6 | Having Fun with Friends 与友同乐 | 58–61（生日派对、晚宴、电影、快餐） | 4 |

**每个单元页的固定内容模式（已抽样确认）**
1. 语法聚焦标签：SIMPLE PRESENT（一般现在时）/ SIMPLE PAST（一般过去时）等
2. Key Vocabulary 核心词汇：按 VERBS / NOUNS / OTHERS（形容词、副词）分类
3. For Special Attention 特别注释：词义辨析、用法、文化背景（如美国成人派对带酒、排队说法、人名 first/last name 等）
4. 分步图解流程：6–8 幅连环插画 + 英文短句（部分单元含人物对话气泡，如打电话、快餐店点餐）
5. 书末附录：美制/公制单位换算表、华氏/摄氏温度对照、美元面额别称（a buck / a quarter / a dime…）

## 四、需求大纲（草案）

### 1. 产品定位
一款基于本书的**中英双语日常英语学习网页**：把 61 个生活场景逐一独立、丰富地呈现（步骤图/句、词汇、注释、对话、发音、自测），支持手机浏览与打印输出，供自己/家人长期学习使用。

### 2. 信息架构
```
首页（目录）
├─ 6 大板块导航（可折叠）＋ 61 单元卡片
│   卡片：单元号、中英标题、语法标签、词数、学习状态、收藏标记
├─ 搜索 / 按板块筛选 / 按语法过滤
└─ 全局进度条

单元详情页（每个场景独立一页）
├─ 场景头部：板块路径、中英标题、语法聚焦、难度
├─ 分步流程 Step 1…N：插图（方案待定）＋ 英文句 ＋ 中文译 ＋ 点读 ＋ 关键词高亮
├─ 对话区（含对话的单元）：对话气泡 ＋ 旁白句对照
├─ 词汇卡：动词/名词/其他分类，音标、中英释义、例句
├─ 特别注释：用法/文化点，中英对照
└─ 学习工具栏：整单元连读 / 逐句跟读 / 自测（听句选义、中译英、打字填空）/ 随机复习

全局能力
├─ 进度与收藏（localStorage 本地存储，无需账号）
├─ 语言切换：仅英文 / 仅中文 / 中英对照
├─ 字号调节、深色模式（可选）
└─ 打印：单场景学习卡 / 章节汇编 / 全册手册 / 词汇总表，A4 适配
```

### 3. 打印设计（重点需求）
- 打印样式独立（`@media print`）：去导航、去交互按钮、A4 分页
- 三种打印单元：① 单场景学习卡（一页一个场景：步骤句＋译文＋词汇表）② 按章节汇编 ③ 全册 61 场景手册（可选）＋ 全书词汇总表
- 中英对照排版，适合朗读/背诵/课堂教学场景

### 4. 技术方案（草案）
- 形态：优先**单文件 HTML**（内联 CSS/JS/数据）→ 手机浏览器直接打开、可分享、可打印、不依赖网络；若用户选多文件则拆分为 HTML/CSS/JS/JSON
- 发音：浏览器 Web Speech API（TTS，免费无版权风险）；不集成书版权音频
- 数据：61 单元内容统一 JSON 结构（单元元信息 / 步骤句 / 对话 / 词汇 / 注释），便于批量生产与维护
- 存储：localStorage；无后端、无登录
- 部署（可选）：GitHub Pages 静态托管

### 5. 内容生产流程
每单元 = 原文转录（步骤句、对话、词汇、注释）→ 中文翻译 → 音标/词性标注 → 关键词高亮 → 数据录入 → 视觉核对
- 插图方案（原图截取 / AI 重绘 / 图标化）待 Q1 确认

### 6. 里程碑
| 阶段 | 内容 | 交付 |
|---|---|---|
| M1 | 需求确认（本大纲） | 确认后开工 |
| M2 | 试点 3 个代表性单元（洗漱 / 开车 / 快餐店） | 样板页面，确认风格 |
| M3 | 前端框架：首页 + 单元页 + 学习/打印功能 | 可运行网页 |
| M4 | 61 单元内容全量生产 | 全量数据 |
| M5 | 移动端与打印打磨、整体验证 | 最终交付 |
